# YouCarYourWay App

This is YourCarYourWay App, used to handle rental car. The new version will handle more features :
- User support
- Multi language interface

Actually, the project only contain a POC for the chat feature. 

## Features
- Authentification
    - create account
    - log in the app
    - password reset
- User profil
    - View
    - Update
    - Delete
- Car rental offer
    - View rental agencies
    - Search for rental offers
    - View rental offer
    - Book a rental offer
- Car rental booking
    - Update a booking
    - Cancel a booking
    - View all bookings
- User support
    - Contact support form
    - Live chat
- Multi langage interface
    - Change interface language
